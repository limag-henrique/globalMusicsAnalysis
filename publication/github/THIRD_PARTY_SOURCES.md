# Source attribution and license scope

CC BY 4.0 applies to the project's original classifications, original compilations
and analytical outputs. Third-party material keeps its own terms. The release
contains numerical research compilations and attribution, not a claim to own or
relicense original third-party archives. Original raw provider files are withheld.

| Source | Research use | Attribution / original access |
|---|---|---|
| Spotify via MGD local archive | Historical Top 200 membership; provider retained | Original chart archive and source manifest retained privately; https://charts.spotify.com/ |
| Kaggle Spotify Charts | Top 200 and Viral 50 membership, 2017–2021 | https://www.kaggle.com/datasets/dhruvildave/spotify-charts |
| YouTube Data API | Contemporary video inventory, separate from historical analysis | https://developers.google.com/youtube/v3/docs/videos/list |

| World Bank WDI | Income, inequality, unemployment, population and digital indicators | Exact API URLs and source hashes in source-attribution.csv; https://data.worldbank.org/ |

Provider authorization for research, import and analysis is distinct from an
upstream public license. The project records owner research/export authorization;
that record is not represented as an upstream CC BY grant. Consult each original
provider before redistributing its original archives or combining their terms
with a new license. No original lyric text or raw chart provider dump is included.

The source-attribution table preserves original public endpoint, collection time,
unit, reference year, methodology and SHA-256 of the privately retained source
artifact. A content-hash reference identifies that artifact; it is not a promise
that the original third-party file is included in this public release.
