## Matt Pocock engineering skills

The skills are installed globally for Antigravity. Use a skill only when the user's request matches its description, and read that skill's `SKILL.md` rather than loading the whole collection. Prefer `implement` for requested code changes, `diagnosing-bugs` for reported failures, `code-review` for review requests, and `writing-for-agents` when editing agent instructions.
