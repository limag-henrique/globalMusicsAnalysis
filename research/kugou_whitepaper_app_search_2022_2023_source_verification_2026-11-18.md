# Kugou 2022–2023 whitepaper source verification

**Finding:** public Kugou search returned playlists associated with the 2022 title and the 2023 `酷狗音乐年度白皮书` account, but it did not expose a complete annual ranked-song table. Keep this result review-only: playlist order does not establish chart rank, and the retrieved sources state no ranking method, annual measurement interval, or geographic market.

Kugou's [public search page](https://www.kugou.com/yy/html/search.html) is a client shell. Its [first-party search script](https://www.kugou.com/yy/static/js/search/search.js) calls the special-playlist endpoint at `https://complexsearch.kugou.com/v1/search/special`; captured helper code and raw responses are archived in the [versioned capture directory](../data/runtime/kugou-whitepaper-source-research-2022-2023-20261118-01/). The signed `白皮书` request returned 15 hits, including a 2022 playlist with 723 advertised songs from account `好听的歌都在这儿了`, and four 2023 playlist results from `酷狗音乐年度白皮书`: a 237-song 1983–2003 classics list, a 49-song music-life list, an 868-song user-generated curated list, and a 755-song annual-music-awards list. The raw first-party search response is [archived here](../data/runtime/kugou-whitepaper-source-research-2022-2023-20261118-01/source-snapshots/kugou-public-search-special-whitepaper-exact-sign.jsonp).

The first-party playlist API returned 714 rows for the 2022 search result (advertised 723), 231 for the 2023 classics result (advertised 237), 49/49 for the music-life result, and 865 for the curated list (advertised 868). Their `sort` sequences have gaps, documented with exact keys and hashes in the [capture report](../data/runtime/kugou-whitepaper-source-research-2022-2023-20261118-01/report.md). These are source-list order anomalies, not chart-rank gaps. The 2023 annual-music-awards search hit advertises 755 songs but has `specialid=0`; the public API returned zero rows, and its first-party songlist URL returned a generic page shell. The archived evidence is the [search record](../data/runtime/kugou-whitepaper-source-research-2022-2023-20261118-01/source-snapshots/kugou-public-search-special-2023-whitepaper.jsonp), [empty API response](../data/runtime/kugou-whitepaper-source-research-2022-2023-20261118-01/source-snapshots/kugou-special-song-api-2023-awards.js), and [generic route response](../data/runtime/kugou-whitepaper-source-research-2022-2023-20261118-01/source-snapshots/kugou-public-songlist-2023-annual-music-awards.html).

No numeric positions or ties were recovered. The original whitepaper document was not retrieved through the public website path; this does not rule out a separate in-app document view. No provider index, catalog, core selection, or previous packet was edited.
